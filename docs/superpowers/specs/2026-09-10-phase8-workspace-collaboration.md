# CareerCrew 第八期：工作台与协作增强规格

## 目标

在第七期质量、权限和观测底座稳定后，把分散的对话、会诊、简历和工具能力组织成可回溯的工作台。所有功能遵循“AI 草案、人工确认、完整留痕”，不自动对外投递或联系 HR。

## 范围

- 跨会话语义搜索、消息书签、从消息创建分支、回答转行动项。
- 会诊的共识/分歧、证据、方案对比矩阵、风险清单和可保存执行计划。
- 简历通用母版、派生版本、版本 diff、经历素材复用、批注和批量导出。
- 工具中心：工具状态、服务端权限范围、调用历史、失败原因和逐项启停。
- 组织/导师/成员协作仅在确认真实多人租户规模后启用；单人产品不提前增加角色复杂度。

## 约束

消息、线程、行动项、计划、简历版本和工具调用都必须 owner/tenant scoped；向量搜索结果必须二次回查归属。会诊证据只展示脱敏的来源摘要，不返回内部工具参数。批量导出异步、限大小、一次性下载并自动过期。MCP HTTP 服务只允许 loopback/受控网络，不能因为工具中心 UI 而暴露未认证入口。

## 验收

用户可以从搜索结果定位原消息、给消息加书签、以截止消息为边界创建分支、把回答转成带来源的行动项；会诊报告能区分共识和分歧并保存计划草案；简历版本差异可解释且批量导出不越权；工具中心能看到最近调用、失败类别和有效权限，启停与高风险操作均有管理员审计。
