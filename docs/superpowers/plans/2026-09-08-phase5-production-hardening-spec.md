# CareerCrew 第五期生产化加固规格

## 目标

在不改变“AI 准备、人工确认、完整留痕”产品边界的前提下，把第四期已验收的完整求职闭环提升为可安全发布、可横向扩展、可观测、可按真实用户数据继续迭代的版本。

## 范围

### 1. 公开分享安全

- 新分享默认开启敏感信息脱敏。
- 分享令牌原文只在创建响应中返回一次，数据库只保存 SHA-256 摘要。
- 已创建的令牌可撤销；过期、撤销、未知令牌统一返回 404。
- 脱敏覆盖邮箱、手机号、座机、身份证号、明确标记的微信号与常见中文地址。
- 公开响应包含 `Cache-Control: no-store`、`X-Robots-Tag: noindex, nofollow`、严格的 `Referrer-Policy` 和 `X-Content-Type-Options: nosniff`。
- 对单个客户端的公开分享解析实施轻量频率限制，并记录成功访问次数及最近访问时间；不记录令牌原文和分享内容。
- 所有权检查继续在创建、列表和撤销接口执行，跨账号行为保持 404 或空列表。

### 2. 上传任务持久化

- 简历解析和知识库摄取任务状态写入 PostgreSQL，任意 worker 都能读取。
- 状态至少包括 `queued/running/done/error`，并记录阶段、进度、错误、结果、尝试次数和更新时间。
- API 进程重启后仍能查询最后状态；对遗留的 `queued/running` 任务返回可解释的中断状态，而不是永久卡住。
- 数据库不可用时允许短时降级到进程内状态，但必须保留当前上传主流程，且不能因为状态持久化故障泄露其他用户任务。

### 3. 发布与迁移演练

- 提供只操作命名临时数据库的发布演练脚本。
- 验证空库到 head、0002 到 head、失败迁移事务回滚与恢复、备份后恢复。
- 脚本从当前 `DATABASE_URL` 派生连接参数，不硬编码实际环境凭据，不修改开发库。
- 演练失败返回非零退出码，并生成包含实际命令结果的 Markdown 报告。

### 4. AI 结构化输出与可观测性

- ATS 分析、材料包和面试情报包使用统一 JSON 对象提取与 Pydantic 模型校验。
- 模型返回无效结构时保留现有模板降级，不向用户暴露内部异常。
- 每次生成记录功能名、结果来源 `llm/template`、耗时、结构化解析是否成功和错误分类；不记录 JD、简历或生成正文。
- 提供仅当前用户可读取的聚合指标接口，至少返回调用数、成功数、模板降级数、降级率和 P95 延迟。

### 5. 搜索与列表扩展性

- 全局搜索接受 `limit` 和不可伪造用户范围的游标，返回 `items/next_cursor`；默认限制结果数量，最大值 50。
- 搜索结果保留类型、标题、摘要、目标 ID，跨账号数据不可见。
- PostgreSQL 启用 `pg_trgm` 并为常用搜索字段添加 GIN trigram 索引。
- 兼容前端现有搜索入口，一次查询只请求一页。

### 6. 模块边界与真实用户事件

- 从超大的 career 路由中拆出分享、AI 生成和搜索模块；原 URL、请求响应和依赖注入方式保持兼容。
- 前端只做必要的 API 类型适配，不进行大规模视觉改版。
- 增加隐私友好的产品事件：保存岗位、生成材料包、采用/复制材料、完成提醒、打开分享面板、生成分享、公开分享成功访问。
- 事件只保存事件名、用户、关联对象、来源和时间，不保存 JD、简历、联系人正文或生成文本。
- 提供当前用户自己的漏斗汇总接口，为 3–5 人、1–2 周试用提供数据基础。

## 不在本期范围

- 自动投递、自动联系 HR、自动接受导师修改。
- 邮件、短信或系统推送服务。
- 录音保存、情绪识别、测谎或基于声音推断人格。
- 在没有真实用户数据前实现公司情报联网引用、完整浏览器扩展或导师批注。

## 验收标准

- 新增行为均有先失败后通过的后端或前端测试。
- 当前前端 TypeScript、Vitest、构建通过；后端相关测试和完整 API 回归通过。
- 迁移在临时数据库完成四条路径演练，开发数据不被改动。
- 浏览器验证至少覆盖：默认脱敏分享、公开响应头、搜索下一页、材料包模板降级、个人漏斗统计。
- 工作区中不得出现明文密码、真实分享令牌、测试账号残留或演练临时迁移文件。
