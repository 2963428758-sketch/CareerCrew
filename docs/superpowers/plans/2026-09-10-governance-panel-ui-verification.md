## 功能边界

- 传统 `/api/knowledge` 上传列表与治理文档是兼容的两条数据链路；传统上传记录尚未自动补建治理文档身份，因此页面明确提示不会伪装成治理文档。
- 当前治理 UI 提供版本、分块预览、单分块编辑、失效日期、可信度、引用命中和整版重索引；单分块编辑会让版本回到 draft/pending，需显式重索引后才恢复 active。
- 单分块编辑 API 为 `PATCH /api/knowledge/governance/documents/{document_id}/versions/{version_id}/chunks/{chunk_id}`，仅文档所有者或管理员可用；公共可读权限不授予修改权限。
- 以上是本地真实服务验收，不代表生产账号、生产数据、生产迁移或生产恢复门禁已经通过。
