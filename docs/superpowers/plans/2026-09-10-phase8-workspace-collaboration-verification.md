# Phase 8 工作台与协作增强验收

更新时间：2026-09-11

## 交付范围

第八期完成了四个 P1/P2 工作台切片，并保持个人账号边界：

- 追溯与行动：owner-scoped 跨会话 embedding 搜索（不可用时 text_fallback）、书签、消息边界分支、来源关联行动项。
- 可解释会诊：共识、分歧、替代方案、证据、风险、报告确认和执行计划确认/撤回。
- 简历母版：母版/派生版本、差异对比、经历素材、批注、异步 PDF/DOCX 批量导出和有限轮询。
- 工具中心：工具状态、MCP 受限说明、有效权限、脱敏调用记录、失败分类、管理员策略和审计。

语义向量索引使用独立的 `careercrew_workspace_messages` 集合；模型或 Qdrant 不可用时搜索 API 明确返回 `text_fallback`，不影响源表搜索和其它工作台动作。

## 数据与安全边界

- 0012–0015 建立工作台关系表；0016 增加消息、会话、报告、简历版本等跨表 owner 组合外键。
- 每个读写 API 都先按当前账号查询资源；ID 不是授权凭据。
- 报告/计划、简历导出、工具启停都是独立用户动作，不会因生成草案自动执行。
- MCP 不在浏览器探测，也不把凭据或 raw arguments 返回给用户。

## 浏览器与 live 数据库验收

本轮启动本地 Docker PostgreSQL/Qdrant 与 FastAPI/Vite，并用临时管理员/普通用户完成真实认证浏览器验收：

1. `/workspace` 工具中心四个工具可见，管理员策略禁用/恢复通过；普通用户看不到启停控件。
2. 管理员打开知识治理和记忆治理入口；记忆搜索框键盘聚焦正常。
3. 375px 与桌面宽度下工作台/知识抽屉无横向溢出；知识抽屉在 375px 实际宽度为 375。
4. 普通用户访问管理员页面重定向，管理员 API 返回 403，管理员简历资源返回 404。
5. 简历导出真实收到 202，页面轮询后显示完成与下载入口。

`browser-harness --doctor` 的 daemon connection 仍不可用，本轮使用 Playwright 1.63 headless fallback；预期的初始 refresh 401 和缺少头像的 404 已区分，不存在 page error 或 HTTP 5xx。详细记录见 [治理面板 UI 验收记录](2026-09-10-governance-panel-ui-verification.md)。

## 组织协作规模决策

当前产品仍以单用户/管理员/质检员为主，尚无已验证的多人组织使用量。因此本期不引入组织、导师、成员、知识库审核和细粒度组织审计；继续保留 owner-scoped 结构，为未来通过 tenant_id/org_id 和 RLS/组合外键扩展留出边界。出现稳定的多人协作需求后再立项，避免现在扩大权限面。

## 发布判定

Phase 8 功能实现、自动化验证和本地真实服务验收已完成；生产数据库迁移/Qdrant 重索引、生产备份恢复、受保护真实模型质量和发布环境容量/故障演练仍是部署门禁，本地未将这些阻塞项误报为通过。
