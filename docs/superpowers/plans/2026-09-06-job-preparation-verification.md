## 三、测试中发现并修复的问题

| 问题 | 级别 | 修复 |
|---|---|---|
| **面试页整页白屏**：`useSpeechRecognition` 用 `useState` 保存 SpeechRecognition 构造函数，React 把函数值当惰性初始化器调用 → `Please use the 'new' operator` → React 卸载整棵树 | **P0（功能不可用）** | 改为模块级常量解析构造器（`useSpeechRecognition.ts` 重写），实测恢复 |
| 模拟面试复盘报告有后端 API 但无 UI 入口，用户不可达 | P1 | 面试页头部新增「生成整场复盘报告」；面试复盘 tab 新增报告列表 + 一键复练（sessionStorage 一次性交接） |
| 迁移 0003 裸字符串执行在 SQLAlchemy 2.x 报错（既有 bug，卡住整条迁移链） | P1（部署阻塞） | `text()` 包装（migrations/versions/0003_user_settings.py） |
| 表单空提交校验、确认弹窗等 | — | 均按预期工作，无需修复 |

另记录：两次「白屏」假象分别为 Vite HMR 半更新脏状态与热更新瞬态（整页重载即恢复），非代码缺陷。
